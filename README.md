# VisionLab

Computer vision / ML research and experimentation project.

## Branch Structure

- `main` — stable release
- `dev` — development integration branch
- `feature/data-pipeline` — data processing pipeline
- `feature/model-zoo` — model architectures
- `feature/evaluation` — evaluation and metrics
- `feature/xai` — explainable AI
- `feature/deployment` — deployment and serving
